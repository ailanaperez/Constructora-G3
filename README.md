# G3 Constructora

Sitio web de G3 Constructora, una constructora de PH ubicada en Ramos Mejía, Buenos Aires.
Proyecto realizado para el curso de Desarrollo Web Jr.

## Propósito

Presentar la empresa, mostrar los proyectos realizados, los PH en venta y
ofrecer un formulario de contacto para consultas.

## Secciones

- Inicio
- Nosotros
- Proyectos
- PH en Venta
- Reseñas
- Contacto

## Tecnologías

- HTML5 semántico
- CSS3 (Flexbox, Grid y Media Queries)
- JavaScript (menú responsive)
- Google Fonts (Poppins)
- Formspree (formulario de contacto)
